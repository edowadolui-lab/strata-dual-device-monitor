# Strata Dual Device Monitor 0.1.0 — Windows preview

Copyright (c) 2026 **edowadolui-lab**. Original monitor and installer: MIT license.

This first installable Windows x64 preview packages the independent dual-device dashboard with an official, checksum-verified Node.js runtime. Extract the ZIP and run `Install.cmd`; no administrator access or separate Node installation is required.

Included:

- Per-user installer and Start-menu/desktop shortcuts.
- Configure Monitor with masked credential entry and protected local settings.
- Start, Stop and Uninstall controls for this monitor's own process.
- Layer assignments and device responsibilities for an existing remote-stage setup.
- Whole-model throughput, primary GPU telemetry, remote host memory/worker status and source freshness.
- Application/runtime licenses, release manifest and SHA-256 checksum file.

Use the [installation guide](https://github.com/edowadolui-lab/strata-dual-device-monitor/blob/main/docs/install.md) and existing [hardware report](https://github.com/edowadolui-lab/strata-dual-device-monitor/blob/main/docs/hardware-report.md). Both user-supplied monitor screenshots are included in the repository documentation.

Prerequisites: Windows 10/11 x64, an existing StrataLink primary metrics API, a compatible remote `/info` telemetry agent, and their credentials. The package does not contain StrataLink, model weights, GPU drivers, DeepSeek Harness or a remote telemetry agent. It does not start, stop or configure inference engines.

Known limits: unsigned preview; AMD GPU utilization/temperature/actual VRAM sensors are unavailable with this agent contract; connection animation is illustrative; agent HTTP response time is not wire latency; model speed and full-context behavior depend on the existing inference deployment.

The release pipeline checks the monitor and runs an isolated Windows installation smoke test before publication. See the linked workflow run for the exact source revision and test output. A clean physical-PC installation and inference tests on other hardware are not established by that packaging test.
